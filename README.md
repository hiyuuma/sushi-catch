# お寿司キャッチ (Sushi Catch) 🍣

流れてくる寿司から「注文票」のネタだけをタップで取る、60秒のブラウザ・アーケードゲーム。
単一の `index.html` だけで動きます（外部アセット・ライブラリなし）。ブラウザで開けばすぐ遊べます。

## 遊び方

- 3レーンを寿司のお皿が流れます。上部の注文票（例：まぐろ×2、えび×1）に載っているネタだけをタップ／クリックしてください。
- 正解すると、その寿司の価格（¥）がお会計に加算されます。連続正解でコンボ倍率アップ。
- 注文票を全部そろえるとボーナス +¥300、次の注文が出ます。
- 間違った寿司や「おとりアイテム」（フライドコーン、プリン、わさび山盛り、からあげ）を取ると、その価格分がお会計から引かれ、コンボがリセットされます。ミス数は記録されます。
- 制限時間60秒。時間経過でベルトが速くなります。

## モード

- **ゆったり** — 通常速度
- **ランチラッシュ** — 流速1.4倍・価格1.5倍

ハイスコアはモード別にブラウザ（localStorage）へ保存されます。

## 結果カード

終了時に、合計円・取った皿数・ミス数・最大コンボ・称号（ランク）を表示。
「結果をXでポスト」「結果をコピー」ボタンからそのまま共有できます。

## ファイル

- `index.html` — ゲーム本体（このファイルだけ）
- `SPEC.md` — 仕様書
- `docs/recon-x-research.md` — 企画前に行ったX需要調査（Grok BuildによるX検索）のレポート

## 作り方について

企画（需要調査）→ 仕様 → 実装 → 検証、という流れで、AIエージェントの役割分担で制作しました。

- 需要調査：Grok Build（X検索）— 寿司打式の「共有できる結果カード」が需要の核だという発見が、円スコアと結果カード仕様の元になっています
- 実装：Cursor（Composer 2.5）
- 企画・仕様・統合・検収：Muse

Muse内でもスペース（Webアプリ）として公開中のバージョンがあります。
